# Типы документов техники и водителей (первая версия)

Решение владельца проекта: вложения, фото и файловое хранилище в первую версию не входят —
только текстовые записи. Список типов документов не зашит в систему.

- Модель `core.DocumentType` (по компании, RLS): вид объекта (`tractor` / `trailer` / `driver`),
  название, показываемые поля (номер, кем выдан, дата выдачи, дата окончания, комментарий),
  обязательные поля (по умолчанию ни одного), до 10 дополнительных текстовых полей, напоминания
  (вкл/выкл и сроки предупреждения в днях), отключение (`is_active`) и архив (`archived_at`).
- Записи `DriverDocument` / `VehicleDocument` получили `doc_type` (PROTECT), `issued_by`, `extra`.
  Старое поле `kind` оставлено для прежних записей; миграции переносят их в типы компании
  (по названиям «Техпаспорт», «Техосмотр», «Разрешение», «Водительское удостоверение» и т.д.).
- Стартовый набор типов создаётся при создании компании и правится компанией как угодно.
- Архив и отключение не удаляют записи и историю; новые записи по отключённому/архивному типу
  запрещены; физического удаления типов нет.
- API: `/api/document-types/?subject=` (создание, правка, `archive`, `unarchive`); права —
  `fleet.view|update` для тягачей и полуприцепов, `drivers.view|update` для водителей, нужен
  включённый модуль. Напоминания: `/api/fleet/reminders/` (окно берётся из типа) и
  `/api/drivers/reminders/`.
- Интерфейс: «Настройки → Типы документов» (вкладки по видам объектов), форма документа в
  карточках техники и водителя подстраивается под выбранный тип.
