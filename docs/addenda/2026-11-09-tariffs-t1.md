# Тарифная система, этап T1: модель тарифов

Единое ТЗ по тарифам (2026-11-08) и уточнение заказчика (2026-11-09): тарифы - данные, которыми
администратор платформы управляет без изменения кода; названия, число, цены, валюты, периоды и
порядок в коде не зашиты. T1 закладывает основу; модули и функции тарифа - T2, лимиты - T3,
изменение тарифа компании - T4, административная панель - T5.

## Что реализовано
- `Plan`: код (неизменяемый), название, описание, период оплаты (`monthly|yearly|lifetime`),
  цена и валюта (любой трёхбуквенный код; цена 0 - бесплатный), порядок показа `sort_order`,
  состояния (черновик / активный / архивный), признак тарифа по умолчанию `is_default`.
  Существующие `limits`, `modules`, `options` сохранены для T2-T3.
- Состояния: черновик - не предлагается; активный - предлагается новым; архивный - не предлагается,
  действующие подписки продолжают работать. БД гарантирует: цена не отрицательна, архивный не
  активен, тариф по умолчанию активен и только один.
- Тариф для новых компаний теперь берётся из данных (`is_default`), а не по коду «start»; нет
  тарифа по умолчанию - создание компании отказывает с понятной ошибкой.
- Правила (`apps/billing/plans.py`): создание (черновик, порядок в конец), правка содержимого без
  влияния на действующие подписки, публикация, снятие, архив, возврат из архива, назначение
  тарифа по умолчанию, удаление (только без подписок и не по умолчанию), порядок показа.
- API администратора платформы `/api/platform/plans/` (только `is_platform_admin`, шлюз подписки
  компании не применяется): список всех состояний с числом подписок, создание, правка, удаление,
  действия publish / unpublish / archive / restore / set-default и `reorder`.
- Публичный список `/api/billing/plans/`: только активные, в заданном порядке, с описанием, ценой
  и валютой.
- Миграция `billing.0006`: поля, ограничения БД, порядок и тариф по умолчанию для существующих
  тарифов (идемпотентно, данные не удаляются).

## Решения и границы
- Цена в T1 - данные для показа и выбора; платёжная система не подключается (платные сервисы без
  согласования не используются).
- Изменение цены тарифа не затрагивает существующие подписки. Как цена применяется к продлению и
  смене тарифа - этап T4.
- Срок бесплатного периода пока константа `FREE_PERIOD_DAYS`; делается настраиваемым в T4.
