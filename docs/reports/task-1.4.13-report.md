## Оговорки
1. Поведение дашборда при new для компаний с заказами в иной валюте изменилось по замыслу: прежде такие заказы исключались, теперь входят по снимку курса (в тесте эквивалентности добавлена явная проверка разницы 9600 = 20 USD*480). Reconcile сравнивает по прежнему правилу и не ломается. Нужно подтверждение заказчика, что это ожидаемо.
2. Запись с KZT-снимком в USD-заказе после смены базы на USD считается prior_base, даже если её валюта совпадает с новой базой (строго по брифу).
3. Ключи `income_kzt/expense_kzt/diff_kzt/month_profit_kzt` сохранены для совместимости, но в new это суммы в базе (код в `currency`).
4. Долги, просрочка и курсовая разница по-прежнему в KZT (`debts_currency`), перевод их на базу не делался.
5. База доли расхода считается по курсу снимка расхода: сумма долей может отличаться от base_amount расхода на копейки округления.
6. Excel: пометки только русские.
